# 部位图标改成肌肉解剖图

日期：2026-10-11　状态：已实现（`miniprogram/core/muscle.ts`，图标登记在 `core/icons.ts`）

## 为什么改

原来的部位图标是线条小人拿着器械（杠铃、哑铃、仰卧起坐），用户反馈「区分不出每个都是什么」。
器械是「怎么练」，用户要认的是「练哪里」。新做法：一个统一的人形剪影，只高亮这个部位练到的肌肉。

## 画法

- **一个母版人形**（64 × 128 坐标，正面 / 背面各一套肌群），每个肌群是独立的形状：胸、三角肌、二头、三头、前臂、腹、腹斜、股四头、小腿、斜方、背阔、下背、臀、腿后侧。
- **每个图标 = 取景框 + 高亮的肌群**：同一个人形，按部位裁出不同的区域（肩到胯、双臂、腰胯、胯到脚），再套上要高亮的肌群。
- **双色靠透明度**：剪影是图标颜色的 27%（整组套一次透明度，重叠处不会变深），高亮是图标颜色本色。所以白底（部位色）、选中（白色图标压在部位色上）、海报圆里（白色）都成立，调用方只给一个颜色。

| 部位 | 视角 | 高亮 |
|---|---|---|
| 胸 | 正面 | 胸大肌 |
| 肩 | 正面 | 三角肌 |
| 手臂 | 正面 | 二头、前臂（只高亮手臂的肌肉） |
| 背 | 背面 | 斜方、背阔、下背 |
| 腹 | 正面 | 腹直肌、腹斜 |
| 腿 | 正面 | 股四头、小腿 |
| 有氧 | — | 不是肌肉，仍是心形 + 心电线 |

进步曲线里的动作图标一并统一：卧推用胸、深蹲用腿、哑铃推肩用肩、硬拉用背面的下背 + 臀 + 腿后侧（`lift-deadlift`）。

## 为以后留的口子

肌群各自独立，所以可以做到「练的是二头还是三头」：`muscleBody('front', ['biceps'], CROPS.arms)` 只高亮二头，
`muscleBody('back', ['triceps'], CROPS.arms)` 只高亮三头。目前部位级图标用的是整个手臂，动作级的高亮还没接到界面上。

## 尺寸

解剖图比线条图需要更大的面积才看得清：

- 今日页、日历页的部位选择行：新增 `icon-chip` 的 `tile` 形状（高 112rpx 的圆角方块），图标 76rpx（原来胶囊 85rpx 高、图标 58rpx）。
- 训练分区标题 42 → 62rpx，今日页推荐条 54 → 72rpx，日历统计 42 → 64rpx，模板小图标 35 → 46rpx。
- 海报邮票里的部位图标 20 → 26px；海报用的白色 PNG 由 `npm run icons` 重新导出。

## 取舍与没验证

- 手臂只用正面，所以看不到三头；动作级高亮接上之后再补。
- 取景框会把人形在画布边缘切掉（躯干图没有腿、腿图没有躯干），这是刻意的，为了让高亮区域足够大。
- 只在浏览器预览里和导出的 PNG 里看过；真机上 SVG 透明度的渲染、模板小图标（23px）是否还认得出，要真机看一眼。
- 徽章里复用了 `part-leg / part-back / part-chest` 三个图标（一头小象、一辆公交车、一头蓝鲸），现在也是解剖图，语义上略微偏了，没有改。
