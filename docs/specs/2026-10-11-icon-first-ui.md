# 图标优先界面（2026-10-11）

目标：少用文字，用图标让页面更简洁。原则：**图标能表达的就不写字；必须有名字的地方，名字放在「选中后的结果」里**（例如选中「煎」后，下面的计算卡片写「煎鸡胸肉 · 150 g」），图标本身带读屏名称（`aria-label`）。

## 改了什么

| 位置 | 之前 | 现在 |
|---|---|---|
| 今日 · 选部位 | 7 个带色点的文字胶囊 + 「今天练什么？」「或者自己选」 | 一条推荐（部位图标 + 部位名 + 一个播放按钮）+ 一排 7 个部位图标 |
| 今日 · 训练中 | 同一排图标，分组标题是色点 + 名称 | 分组标题的色点换成部位图标；动作下方只留「上次 57.5kg×8」，不再写每组 kcal；未满足完成条件的长文案改为点击时的一句 toast |
| 日历 | 文字胶囊选部位；模板每天一个文字标签；「本月各部位次数」圆点 + 名称 | 部位图标；模板每天 = 该日部位图标串（休息 = 月亮）；次数 = 图标 + 数字；训练消耗 / 饮食摄入用图标 + 数字 |
| 饮食 | 「1 · 选择肉类」「2 · 选择做法」「3 · 食用分量」三个标题，选项全是文字 | 6 种肉各一个动物 / 食材图标（下方小字 = 每 100g kcal）；6 种做法各一个厨具图标（下方小字 = 额外 kcal）；主食 / 蔬果也是图标，份量改为 ½ 1 2 |
| 推荐 | 「热量来源 · 蛋白质 23% …」「点卡片看做法」「未收录」「记入今日饮食」「撤回」「下一道」 | 三个带色点的百分比（与进度条同色）+ 翻面图标、「新」、「+ 记入」、撤回 / 下一道只留图标；背面去掉小标题，收藏 / 分享只留图标 |
| 我的 | 标题与统计标签都是文字 | 标题与三项统计（打卡天数 / 最长坚持 / 周均）换成图标 + 数字，热力图图例去掉「少 / 多」 |
| 引导 | 「第 1 / 4 步」、目标说明、每周次数说明、体重说明 | 进度点；目标 = 哑铃 / 火焰 / 心率 三个图标；最后一步 = 「选部位 → + → 勾」三个图标 |

## 新组件

`<icon-chip icon fg bg bd sub label on shape size>`：`shape="pill"` 是一排图标的胶囊（部位），`shape="box"` 是图标 + 一行小字的方块（食材、做法）。点击事件仍然挂在组件标签上（`bindtap` + `data-*`）。

## 有意保留的文字

动作名称、日期、数据数值与单位、挑战 / 徽章等「必须读」的内容；`ⓘ` 说明气泡里的解释；按钮里的「下一步」「开始」「记入」这类 2–3 字动词。
