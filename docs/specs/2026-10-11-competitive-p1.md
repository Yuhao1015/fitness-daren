# 竞品分析 P1 落地

日期：2026-10-11　依据：对 Hevy、Strong、Fitbod、Keep、训记等 13 个竞品的调研得出的 P1-1 ～ P1-7　状态：已实现（都只改小程序端，不需要云开发）

## P1-1 部位图块显示恢复状态（今日页、日历页）

- 7 个部位图块右上角一个小数字：距上次**完成**这个部位的训练几天（7 天以上写 7+，30 天内没练过不显示）。日历页按选中的那一天算。
- 48 小时内（1 天内）练过的力量部位，图标变淡到 45%；已经选中的图块不变淡，选中态要清楚。有氧不变淡。
- 读屏名称带上「N 天没练」。代码：`viewmodels/common.ts` 的 `partRest / partChips`，`icon-chip` 新增 `badge`、`dim` 属性。

## P1-2 「我的」页本周肌群人体图

- 12 周热力图下面：正面、背面两个完整人形，每块肌肉按这一周的完成组数分 3 档深浅（1–4 / 5–9 / 10 组以上），右侧图例；左右箭头翻周，最多回看 11 周。
- 组数口径：每个动作配了主要肌群和协同肌群（`core/muscle-map.ts` 的 `EXERCISE_MUSCLES`，24 个动作全覆盖），主要肌群每组算 1 组，协同算半组；只算已完成训练日里打了勾的组。
- 人形复用部位图标的同一套肌群形状（`core/muscle.ts` 的 `bodyMapSvg`）。

## P1-3 专注模式的动作小人形

- 动作名左边一个小人形，只高亮这个动作的主要肌群（卧推 → 胸；引体 → 背阔；绳索下压 → 三头；深蹲 → 大腿前侧……）。
- 自动选能看到更多主要肌群的那一面，再按肌群选取景（手臂 / 腹 / 腿 / 后链 / 躯干）。每个动作登记为图标 `ex-<动作 id>`。

## P1-4 第一次训练的情境提示

- 还没完成过任何一次训练的用户：推荐条的 ▶ 出 3 次呼吸光圈 → 进入训练后光圈移到第一个动作的「+」→ 加了组后移到第一组的「✓」→ 打了勾就消失。
- 没有文字气泡；判断条件是「累计打卡 0 次」，完成第一次训练后自然不再出现，不需要额外的本地标记。关闭动效时光圈是静止的描边。

## P1-5 连续达标 N 周

- 「我的」页三项统计里，「平均每周」换成「连续达标 N 周」（日历 + 对勾图标）：从最近一个达标的周往前数，每周训练天数 ≥ 每周目标；本周还没过完，没达标不打断。
- 月报海报页头右侧加「连续达标 N 周」（N 为 0 或旧的月报记录没有这个字段时不画）。

## P1-6 饮食页「常吃」挪到最上面

- 常吃移到蛋白质进度条下面，点一下直接记入。
- 所有「记入」（肉类计算、主食蔬果、常吃）的提示条都带「撤回」按钮，点了删掉刚记入的那一条。`toast` 组件新增可选的动作按钮（`toast(page, msg, action)` + `bind:action`）。

## P1-7 徽章入口卡

- 「我的」页徽章墙入口改成整行卡片：已获得数 / 总数、最近得到的 3 枚小徽章（新的在前，一枚没有时是虚线空位）、「下一枚」的名称和进度条。
- 「下一枚」跳过已经拥有的、以及条件已满足只等下次完成训练时发放的徽章。

## 做的取舍（rulings）

- **「刚练过」按 1 天内算**：报告写「48 小时内」。前天练的到今天已满 48 小时左右，再变淡会让一周练 3 次的人每次都看到大半图块是淡的。代价：前天练过的部位不提示（日历选中日的文字提示仍按原来的 2 天规则）。
- **新手光圈用「累计打卡 0 次」判断，没有写本地标记**：效果一样，少一个存储键。代价：一直没完成第一次训练的用户每次进来都会看到光圈（3 次后停）。
- **协同肌群按半组计**：报告没有规定口径，半组是常见的简化做法。代价：协同肌群的档位偏高或偏低时，只要改 `weeklyMuscleSets` 一处。
- **「我的」页剩下的 3 个入口仍是两列网格**，最后一行只有一个，没有重新排。
