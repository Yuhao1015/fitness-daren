# 邮票版打卡海报

日期：2026-10-11　状态：已实现（`miniprogram/core/poster/stamp.ts`）

## 为什么改

打卡海报是传播的主要载体，经典版是「白底卡片 + 数据」，和别的健身 App 的分享图长得差不多，
看不出这是「打卡」。灵感来自 Collect UI 的 Stamp 分类：把每一次打卡做成一枚邮票，
天数是面值，盖上当天的邮戳，攒起来就是一本集邮册。这是一个**换排版**的改动，不动数据。

## 版式（宽 310，逻辑像素，导出 ×3）

- 米色纸（`#F4EFE2`）上放一枚白色邮票，四边齿孔：孔心在边线上，用纸色的小圆盖掉邮票边缘。
- 邮票内有一个绿色印刷框；框内从上到下：应用名与编号 `No.xxx` → 浅绿画面（大号坚持天数 + 「天」、一句「今日训练已完成」、当天训练的部位图标）→ 完成组数 / 训练容量 / 消耗三列 → 新纪录条（有才画）。
- 邮戳压在邮票右下角、一半探出邮票：斜 -12° 的双线圆，里面是年、月.日、星期，左边拖三条波浪消印线。印刷框底部固定留 36 的空白，保证邮戳不压住任何内容。
- 邮票下面的纸边：趣味文案（整行宽度、最多两行，不再和邮戳抢位置）→ 本月打卡热力（格子换成适合米色纸的颜色）→ 虚线 + 小程序码 / 「微信搜索」。

## 取舍

- **数据结构不变**：沿用 `CheckinPosterData`。相册里已存的海报、分享落地页重绘时都自动变成邮票版，不需要迁移。
- **新增两条画布指令**：`rotate`（绕一点旋转，到下一个 `restore` 为止）与 `restore`，用来斜着盖邮戳。服务层 `services/canvas.ts` 用 `ctx.save / translate / rotate / restore` 实现，都是 Canvas 2D 标准接口。
- **波浪线用短线段拼**：画布指令里没有曲线，每 3px 一段，三条线共约几十个指令，可以忽略。
- **经典版 `buildCheckinPoster` 保留**：它的 `drawFooter`、`drawMonthHeat` 还被月报等海报复用，原有测试也在；页面不再调用它。是否彻底删掉经典版，等产品拍板。
- **`drawFooter` 多了一个可选参数 `lineColor`**，虚线颜色要适配米色纸，默认值不变。

## 没验证

- 只在浏览器预览里看过效果（Canvas 引擎是浏览器的）。真机上 `rotate`、字体 `Outfit` 加载、导出 PNG 的清晰度，需要在开发者工具和真机上各看一遍。
- 页面里没有「切换回经典版」的入口。
